Component

Settings row

Icon, label, and a trailing chevron — a single tappable settings entry.

Preview

Notifications

Guidelines

  • Icon is always accent-primary; the chevron is always ink-35 — that contrast is what signals "tappable" vs. "decorative."
  • Every row but the last in a list gets a 1px ink-8 bottom border; the last row has none (see Settings list).
  • Label is always a single line — if a setting needs a description, that belongs on the destination screen, not wrapped into this row.
