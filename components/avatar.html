Guidelines

  • Default size for anything alongside body text (headers, list rows); large size only for the Profile screen's own identity.
  • Always shows a single initial, uppercase, never a photo or icon.
  • Background is always --color-accent-secondary — it's the one place that color is used as a solid fill this large.
