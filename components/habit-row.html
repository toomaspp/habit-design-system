Guidelines

  • One row per habit, stacked in a vertical list with a 10px gap (see the Habit list pattern).
  • Icon reflects the habit's category (clock for time-based, droplet for hydration, book for reading, etc.) — pick something recognizable at 20px, not decorative.
  • The check control only fills accent-primary when the habit is actually completed for today; otherwise it stays a plain outline — never a third "in progress" state.
  • The ghost row (dashed border, no background) is reserved for the "add a habit" action — don't reuse that style for anything else.
