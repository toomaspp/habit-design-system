Stat tile

A single number with a caption underneath, used for at-a-glance metrics.

Guidelines

  • Value accepts any short content — a number, percentage, or short text — always Title 22/semibold.
  • Used 3-up in a row with a 10px gap (see the Stats and Profile screens); the tile itself fills the available width rather than a fixed size.
  • Never nest another card inside a stat tile — it's an endpoint, not a container.

Code

<div class="stat-tile"> <span class="value">12</span> <span class="caption">Day streak</span> </div>
